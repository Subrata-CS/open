# Variables and Data Types

## Overview

A **Variable** is a named container that stores a piece of information (a value) inside a computer's memory, so a program can use, change, or refer to that information later. A **Data Type** tells the computer *what kind* of information is being stored — a whole number, a decimal number, a single letter, or a longer piece of text — because different kinds of data need to be stored differently in memory.

Think of a variable like a labeled box in a warehouse. You write a label on the box (the variable name), and you put something inside it (the value). But before you even use the box, you need to know *what kind* of box it is — a box for storing liquids is built differently than a box for storing books. In the same way, a computer needs to know in advance whether a variable will hold a whole number, a decimal, or a letter, because each type is stored differently in memory and takes up a different amount of space.

This is why, in many programming languages like C, you must **declare** a variable's type before using it — you're essentially telling the computer, "I need a box, and it needs to be the kind that holds whole numbers," before you're allowed to put anything inside it.

## Key Concepts

- **Variable Declaration** — Telling the computer to reserve memory space for a variable, along with its name and type, e.g., `int age;`
- **Variable Initialization** — Giving a variable its first value at the same time you declare it, e.g., `int age = 25;`
- **Assignment** — Changing the value stored in a variable after it already exists, using the `=` sign, e.g., `age = 30;`
- **Naming Rules** — Variable names must start with a letter or underscore (not a number), can only contain letters, numbers, and underscores, cannot use spaces or reserved keywords (like `int` or `if`), and are case-sensitive (`age` and `Age` are different variables).
- **Data Type** — Defines what kind of value a variable can hold (whole number, decimal, character, etc.) and how much memory it needs.
- **Type Conversion** — Converting a value from one data type to another, either automatically (**implicit**) or manually by the programmer (**explicit**, also called "type casting").
- **Constant** — A value that, once set, cannot be changed later in the program, declared using the `const` keyword, e.g., `const float PI = 3.14;`
- **Scope** — Where in the program a variable is accessible from — a variable declared inside a function is usually only usable within that function (**local**), while one declared outside all functions can be used anywhere in the program (**global**).
- **Storage Class** — Controls a variable's lifetime (how long it exists in memory) and visibility (where it can be accessed from) — covered in detail below.
- **sizeof() Operator** — A built-in operator that tells you exactly how many bytes of memory a data type or variable occupies.

## Signed vs Unsigned — What's the Difference?

Every whole number type (`int`, `short`, `long`) can be either **signed** (default) or **unsigned**:

- **Signed** — Can store both positive and negative numbers. Half the range is used for negative values, half for positive.
- **Unsigned** — Can only store zero and positive numbers, but in exchange, it can store a *larger maximum* positive value, since no space is "wasted" on negative numbers.

```c
int signedNum = -50;           // valid
unsigned int unsignedNum = -50; // invalid logically — becomes a huge positive number instead!
```

This is a common beginner mistake — assigning a negative number to an `unsigned` variable doesn't cause an error, but it silently wraps around to a very large positive number instead, which can cause confusing bugs.

## Storage Classes — Controlling Lifetime and Visibility

A **storage class** decides *how long* a variable stays in memory and *where* in the program it can be accessed from:

| Storage Class | Lifetime | Visibility | Default Value |
|---|---|---|---|
| `auto` | Exists only within the block/function it's declared in | Local only | Garbage (unset) |
| `static` | Exists for the entire program's runtime, even after the function ends | Local (but remembers its value between calls) | 0 |
| `extern` | Exists for the entire program's runtime | Can be shared across multiple files | 0 |
| `register` | Exists only within the block/function | Local only | Garbage (unset) |

```c
#include <stdio.h>

void counter() {
    static int count = 0; // static keeps its value between function calls
    count++;
    printf("Count: %d\n", count);
}

int main() {
    counter(); // Output: Count: 1
    counter(); // Output: Count: 2
    counter(); // Output: Count: 3
    return 0;
}
```

Notice how `count` doesn't reset to 0 every time `counter()` is called — because it's `static`, it remembers its previous value across multiple function calls, unlike a normal (`auto`) local variable which would reset every time.

## Example — Using Every Major Data Type Together, Step by Step

Let's write one complete program that uses **every major data type**, so you can see them all working side by side.

```c
#include <stdio.h>

int main() {
    int age = 25;
    float height = 5.9;
    double distance = 384400.756;
    char grade = 'A';
    int isStudent = 1; // Acting as a boolean: 1 = true, 0 = false
    char name[20] = "Rahul";
    int a, b, c; // Multiple variables declared in one line

    a = 1; b = 2; c = 3;

    printf("Name: %s\n", name);
    printf("Age: %d\n", age);
    printf("Height: %.1f feet\n", height);
    printf("Distance: %.3lf km\n", distance);
    printf("Grade: %c\n", grade);
    printf("Is Student: %d\n", isStudent);
    printf("a=%d, b=%d, c=%d\n", a, b, c);
    printf("Size of int: %lu bytes\n", sizeof(age));
    printf("Size of double: %lu bytes\n", sizeof(distance));

    return 0;
}
```

## Example — Type Conversion (Implicit vs Explicit)

```c
#include <stdio.h>

int main() {
    int wholeNumber = 9;
    float result;

    // Explicit conversion (type casting) - done manually by the programmer
    result = (float) wholeNumber / 2;

    printf("Result: %.2f\n", result);

    return 0;
}
```

Here, `(float) wholeNumber` **explicitly** converts the integer 9 into a float *before* dividing by 2. Without this cast, dividing two integers (`9 / 2`) in C would give `4` (losing the decimal part), because integer division drops anything after the decimal point. By casting to float first, we correctly get `4.50` as the result.

- **Implicit Conversion** happens automatically, without you writing anything special — for example, if you assign an `int` value to a `float` variable, C automatically converts it for you behind the scenes.
- **Explicit Conversion (Type Casting)** happens when you deliberately force a value from one type into another, by writing the target type in parentheses before the value, like `(float) wholeNumber`.

## Escape Sequences — Special Characters in Strings and Chars

Sometimes you need to represent characters that can't be typed directly, like a new line or a tab. These are written using a backslash `\`:

| Escape Sequence | Meaning |
|---|---|
| `\n` | New line |
| `\t` | Tab space |
| `\\` | A single backslash character |
| `\'` | A single quote character |
| `\"` | A double quote character |
| `\0` | Null character (marks the end of a string in C) |

```c
printf("Hello\nWorld\t!\n");
```

This prints "Hello", then moves to a new line, prints "World", adds a tab space, then "!".

## Naming Convention Best Practices

While C allows flexible variable names, following consistent naming styles makes code much easier to read:

- **camelCase** — `studentAge`, `totalMarks` (common in many languages, capitalize each word after the first)
- **snake_case** — `student_age`, `total_marks` (common in C, words separated by underscores)
- Use meaningful names (`age` instead of `a`, `totalPrice` instead of `tp`) so your code is understandable without extra comments.
- Avoid starting variable names with a number, and avoid using reserved keywords (`int`, `return`, `if`, etc.) as variable names.
