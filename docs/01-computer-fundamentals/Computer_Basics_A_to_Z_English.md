# 1. What is a Computer?

A **computer** is an electronic machine that accepts **input**, processes data, stores information, and produces **output**.

# 3. Hardware and Software

| Hardware | Software |
|---|---|
| Physical parts | Programs |
| Monitor | Windows |
| Keyboard | MS Word |
| Mouse | Google Chrome |
| Printer | Paint |

**Easy Rule**

- Hardware = You can touch it.
- Software = You cannot touch it.

---

# 4. Memory and Storage

| Type | Purpose |
|---|---|
| RAM | Temporary memory while working |
| ROM | Permanent startup memory |
| HDD | Large storage device |
| SSD | Fast storage device |
| USB Drive | Portable storage |

---

# 5. Operating System

An **Operating System (OS)** controls the entire computer.

Examples:

- Windows
- Linux
- macOS
- Android

Functions:

1. Starts the computer
2. Opens programs
3. Manages files
4. Controls hardware

---

# 6. Desktop

The **Desktop** is the first screen after Windows starts.

Common icons:

| Icon | Purpose |
|---|---|
| This PC | Open drives |
| Recycle Bin | Deleted files |
| Folder | Store files |
| Browser | Internet |

|---|---:|

- `=MAX(A1:A5)`

# 14. Computer Safety

1. Never share passwords.
2. Use strong passwords.
3. Update Windows regularly.
4. Install antivirus software.
5. Backup important files.
6. Avoid suspicious links.
