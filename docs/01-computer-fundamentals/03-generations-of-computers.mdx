## First Generation (1940–1956)

![First](/img/first-generation.jpg)

Technology: **Vacuum Tubes**

![Vacuum Tube](/img/vacuum-tube.jpg)

### Features

- Very large size
- Machine language
- High heat
- Expensive

---

## Second Generation (1956–1963)

![Second](/img/second-generation.jpg)

Technology: **Transistors**

![Transistor](/img/transistor.jpg)

### Improvements

- Smaller
- Faster
- Less heat
- More reliable

---

## Third Generation (1964–1971)

![Third](/img/third-generation.jpg)

Technology: **Integrated Circuits**

![IC](/img/integrated-circuit.jpg)

### Features

- Multiprogramming
- Smaller computers
- Higher speed

---

## Fourth Generation (1971–Present)

![Fourth](/img/fourth-generation.jpg)

Technology: **Microprocessor**

![Microprocessor](/img/microprocessor.jpg)

### Examples

- Desktop
- Laptop
- Tablet
- Smartphone

---

## Fifth Generation (Present & Future)

![Fifth](/img/fifth-generation.jpg)

Technology: **Artificial Intelligence**

![AI](/img/ai-computer.jpg)

### Applications

- ChatGPT
- Robotics
- Self-driving Cars
- Machine Learning
