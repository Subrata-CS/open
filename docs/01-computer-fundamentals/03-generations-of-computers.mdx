# Generations of Computers

<Lede>
The previous topic followed the story machine by machine. This one groups those
machines into five generations — and the grouping is not by date, it is by the
one component doing the switching inside. Get that idea and the whole table
below stops being something to memorise and starts being something you can work
out.
</Lede>

## Overview

Every computer works by switching electric current on and off, billions of times
a second. A **generation** is named after whatever performs that switch. Change
the switch and everything else follows: the size, the speed, the heat, the
memory, even the language people write programs in.

<Callout kind="def" title="Definition">
  A generation of computers is a stage of development identified by the
  electronic component used for switching and processing — vacuum tubes,
  transistors, integrated circuits, microprocessors, and now ULSI chips with
  artificial intelligence.
</Callout>

## Key Concepts

### The one table that answers most questions

| | First | Second | Third | Fourth | Fifth |
| --- | --- | --- | --- | --- | --- |
| **Period** | 1946–1959 | 1959–1965 | 1965–1971 | 1971–1980 | 1980–present |
| **Technology** | Vacuum tube | Transistor | Integrated circuit (SSI, MSI) | Microprocessor (LSI, VLSI) | ULSI, AI |
| **Memory** | Magnetic drum | Magnetic core | Semiconductor, magnetic disk | Semiconductor, VLSI | Very large semiconductor, optical |
| **Language** | Machine language | Assembly, FORTRAN, COBOL | FORTRAN, COBOL, PASCAL, BASIC | C, C++, DBASE | Python, Java, AI and natural language |
| **Speed** | Milliseconds | Microseconds | Nanoseconds | Nanoseconds and below | Picoseconds, parallel |
| **Size** | A whole room | A large cupboard | A desk | A lap | A pocket |
| **Examples** | ENIAC, UNIVAC I | IBM 1401, IBM 7094 | IBM 360, PDP-8 | IBM PC, Apple II, CRAY-1 | Laptops, PARAM 10000 |

<Callout kind="warn" title="Careless-mistake trap">
  Third generation is the **integrated circuit**, not the transistor — the
  transistor is second. The IC contains transistors, which is exactly why
  students swap the two. And the microprocessor is fourth, not third, even
  though it is also a chip.
</Callout>

Chips are graded by how many components they hold, and the names come up in
one-mark questions:

| Scale | Stands for | Components on one chip |
| --- | --- | --- |
| **SSI** | Small Scale Integration | Up to about 100 |
| **MSI** | Medium Scale Integration | About 100 to 1,000 |
| **LSI** | Large Scale Integration | About 1,000 to 10,000 |
| **VLSI** | Very Large Scale Integration | 10,000 to about a million |
| **ULSI** | Ultra Large Scale Integration | More than a million |

So the boundary that separates a fourth-generation chip from a fifth-generation
one is simply:

<Eq block>{String.raw`\text{ULSI} \;:\; N_{\text{transistors}} > 10^{6}`}</Eq>

### Generation by generation

**First generation (1946–1959).** Vacuum tubes did the switching. The machines
filled rooms, needed air conditioning, drew enormous power, and failed
constantly because tubes burn out like bulbs. Input came on punched cards,
output on printouts, and programs were written in machine language — raw binary.

**Second generation (1959–1965).** The transistor, invented at Bell Labs in
1947, replaced the tube. Machines became smaller, cheaper, cooler and far more
reliable. Magnetic core memory arrived, and so did the first languages a human
could read: **FORTRAN** for science, **COBOL** for business.

**Third generation (1965–1971).** Jack Kilby's integrated circuit put many
transistors on a single silicon chip. This generation gave us the keyboard and
monitor in place of cards and printouts, and an operating system that could hold
several programs in memory at once — **multiprogramming**.

**Fourth generation (1971–1980).** The Intel 4004 put an entire CPU on one chip.
That single change created the personal computer, and with it the graphical
interface, the mouse, and networks joining machines together into what became
the internet.

**Fifth generation (1980–present).** Defined by what the machine is asked to do
rather than what it is made of: understand speech, recognise images, answer
questions, learn from data. The hardware is ULSI and massively parallel; the
subject is **artificial intelligence**.

## Example

The five generations are a lookup table, and a lookup table is a dictionary.
This one answers the question an exam actually asks — given a technology, which
generation is it?

```python
# 1. INPUT — the defining technology of each generation
generations = {
    1: "Vacuum tube",
    2: "Transistor",
    3: "Integrated circuit",
    4: "Microprocessor (VLSI)",
    5: "ULSI with artificial intelligence",
}

# 2. PROCESS — search the table the other way round
def which_generation(technology):
    for number, tech in generations.items():
        if technology.lower() in tech.lower():
            return number
    return "not listed"

# 3. OUTPUT
for number, tech in generations.items():
    print(f"Generation {number}: {tech}")

print("Transistor belongs to generation", which_generation("transistor"))
```

Expected output:

```text
Generation 1: Vacuum tube
Generation 2: Transistor
Generation 3: Integrated circuit
Generation 4: Microprocessor (VLSI)
Generation 5: ULSI with artificial intelligence
Transistor belongs to generation 2
```
