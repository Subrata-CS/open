# Computer Basics

## Overview

A **computer** is an electronic device that accepts **data (input)**, processes it according to instructions, stores information, and produces meaningful **output**. Modern computers are used in education, business, healthcare, science, entertainment, artificial intelligence, and almost every part of daily life. <Cite refs={["turn0search5","turn0search11"]}/>

## Why Computers Matter

Computers have transformed the world because they can solve problems much faster and more accurately than humans for repetitive tasks.

| Area | Example |
|---|---|
| Education | Online learning, digital classrooms |
| Healthcare | Medical diagnosis, MRI analysis |
| Business | Accounting, inventory management |
| Communication | Email, video calls, messaging |
| Science | Weather prediction, space research |
| AI | Machine learning, robotics |

**Example**

- **Input:** You press the `A` key.
- **Process:** The CPU interprets the signal.
- **Output:** The letter appears on the screen.
- **Storage:** The document can be saved to an SSD.

## Hardware vs Software

| Hardware | Software |
|---|---|
| Physical parts | Programs and applications |
| CPU, RAM, Keyboard | Windows, Linux, Chrome |
| Can be touched | Cannot be touched |
| Manufactured | Developed by programmers |
