# Computer Hardware

<Lede>
Computer hardware refers to every physical component of a computer system. It includes the processor, motherboard, memory, storage devices, keyboard, monitor, printer, and every electronic part that can be touched.
</Lede>

---

## What is Computer Hardware?

<Callout kind="def" title="Definition">
Computer hardware is the collection of all physical electronic and mechanical components that make up a computer system.
</Callout>

A computer cannot work using hardware alone. Hardware performs the physical work while software provides the instructions.

# Internal Hardware

## 1. Central Processing Unit (CPU)

![CPU](/img/cpu.jpg)

*Figure 1. Central Processing Unit*

The **CPU** is known as the **Brain of the Computer** because it performs calculations, logical operations, and executes instructions.

### Features

| Feature | Description |
|---|---|
| Full Name | Central Processing Unit |
| Function | Executes instructions |
| Speed | Measured in GHz |
| Operations | Arithmetic & Logical |
| Examples | Intel Core i7, AMD Ryzen |

### Main Functions

- Executes program instructions
- Controls computer operations
- Performs calculations
- Processes data

<Callout kind="tip" title="Did You Know?">
A modern CPU can perform billions of instructions every second.
</Callout>

---

## 2. Motherboard

![Motherboard](/img/motherboard.jpg)

*Figure 2. Desktop Motherboard*

The **Motherboard** is the main printed circuit board (PCB) that connects every hardware component together.

### Main Parts

| Component | Purpose |
|---|---|
| CPU Socket | Holds the processor |
| RAM Slots | Install memory modules |
| PCIe Slot | Graphics & expansion cards |
| BIOS Chip | Starts the computer |
| SATA Port | Connects HDD & SSD |

### Real-Life Example

The motherboard is like the **road network of a city**. Every component communicates through it.

---

## 3. RAM (Random Access Memory)

![RAM](/img/ram.jpg)

*Figure 3. DDR4 RAM Module*

RAM stores data **temporarily** while applications are running.

<Callout kind="note" title="Important">
RAM is **volatile memory**, meaning all data disappears when the computer is powered off.
</Callout>

### Example

When you open Photoshop:

1. The application loads into RAM.
2. CPU processes images.
3. Saved files are written to SSD.

---

## 4. Storage Devices

![SSD and HDD](/img/ssd-hdd.jpg)

*Figure 4. SSD and HDD Storage Devices*

Storage keeps data permanently.

### Types of Storage

| Device | Speed | Capacity |
|---|---|---|
| HDD | Slow | Very High |
| SSD | Fast | High |
| NVMe SSD | Very Fast | High |

### HDD vs SSD

| Feature | HDD | SSD |
|---|---|---|
| Moving Parts | Yes | No |
| Speed | Slow | Fast |
| Noise | Yes | Silent |
| Durability | Lower | Higher |
| Power Use | Higher | Lower |

# Python Demonstration

```python
hardware = {
    "CPU": "Intel Core i7",
    "RAM": "16 GB",
    "Storage": "512 GB SSD",
    "Monitor": "24 inch LED"
}

for device, value in hardware.items():
    print(device, ":", value)
```

### Output

```text
CPU : Intel Core i7
RAM : 16 GB
Storage : 512 GB SSD
Monitor : 24 inch LED
```

# Interview Questions

### Q1. What is hardware?

Hardware refers to every physical electronic component of a computer system.

### Q2. What is the difference between RAM and SSD?

RAM stores temporary data, while SSD stores permanent data.

### Q3. Why is the motherboard important?

It allows communication between the CPU, RAM, storage, graphics card, and other devices.
