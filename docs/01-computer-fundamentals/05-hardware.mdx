# Computer Hardware

<Lede>
Computer hardware refers to every physical component of a computer system. It includes the processor, motherboard, memory, storage devices, keyboard, monitor, printer and every electronic part that can be touched.
</Lede>

---

## What is Hardware?

<Callout kind="def" title="Definition">
Hardware is the collection of all physical electronic and mechanical components of a computer system.
</Callout>

A computer cannot work using hardware alone. Hardware performs the physical work while software provides the instructions.

### Real-Life Example

| Human Body | Computer Hardware |
|---|---|
| Brain | CPU |
| Memory | RAM |
| Eyes | Monitor |
| Hands | Keyboard & Mouse |
| Skeleton | Cabinet |
| Heart | Power Supply |

# Internal Hardware

## CPU (Central Processing Unit)

![CPU](/img/hardware/cpu.jpg)

*Figure 1. Intel Processor*

The CPU is called the **Brain of the Computer** because it executes instructions and controls every operation.

| Feature | Description |
|---|---|
| Full Name | Central Processing Unit |
| Function | Processes instructions |
| Speed | GHz |
| Performs | Arithmetic & Logical Operations |
| Example | Intel Core i7, AMD Ryzen |

### Functions

- Execute instructions
- Perform calculations
- Control hardware
- Process data

---

## Motherboard

![Motherboard](/img/hardware/motherboard.jpg)

*Figure 2. Desktop Motherboard*

The motherboard is the **main printed circuit board (PCB)** that connects every component together.

### Main Components

| Component | Purpose |
|---|---|
| CPU Socket | Holds processor |
| RAM Slot | Memory installation |
| PCIe Slot | Graphics card |
| BIOS Chip | Starts computer |
| SATA Port | Connect storage |

---

## RAM (Random Access Memory)

![RAM](/img/hardware/ram.jpg)

*Figure 3. DDR4 Memory Module*

RAM stores data temporarily while applications are running.

<Callout kind="note" title="Important">
RAM is **volatile memory**. Data disappears when power is turned off.
</Callout>

### Example

When editing a photo:

1. Image loads into RAM.
2. CPU processes it.
3. SSD saves the final file.

---

## Storage Devices

![SSD and HDD](/img/hardware/ssd-hdd.jpg)

*Figure 4. Permanent Storage Devices*

Storage keeps files permanently.

| Storage | Speed | Lifespan |
|---|---|---|
| HDD | Slow | Medium |
| SSD | Fast | High |
| NVMe SSD | Very Fast | High |

### HDD vs SSD

| Feature | HDD | SSD |
|---|---|---|
| Moving Parts | Yes | No |
| Noise | Yes | Silent |
| Speed | Low | High |
| Power Use | Higher | Lower |

# Python Demonstration

```python
hardware = {
    "CPU":"Intel Core i7",
    "RAM":"16 GB",
    "Storage":"512 GB SSD",
    "Monitor":"24 inch LED"
}

for device in hardware:
    print(device, ":", hardware[device])
```

### Output

```text
CPU : Intel Core i7
RAM : 16 GB
Storage : 512 GB SSD
Monitor : 24 inch LED
```

# Interview Questions

### Q1. What is hardware?

Hardware refers to every physical electronic component of a computer.

### Q2. Difference between RAM and SSD?

RAM stores temporary data while SSD stores permanent data.

### Q3. Why is the motherboard important?

It allows communication between the CPU, RAM, storage, graphics card and every other device.
