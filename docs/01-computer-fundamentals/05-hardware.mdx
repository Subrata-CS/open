# Hardware

<Lede>
Hardware is the physical part of a computer that you can see and touch. Every computer system is made of hardware and software working together. This chapter explains all important hardware devices from the motherboard to printers.
</Lede>

## Overview

A computer system has two major parts:

- **Hardware** → Physical components
- **Software** → Programs and instructions

<Callout kind="def" title="Definition">
**Hardware** is the collection of physical and tangible components of a computer system, including internal parts and external peripheral devices.
</Callout>

## Key Concepts

### Internal Hardware

Internal hardware is installed inside the computer cabinet and performs processing, memory and storage functions.

#### Motherboard

<AsyncImageGroup
  query={[
    "computer motherboard top view",
    "ATX motherboard labeled",
    "desktop motherboard close up"
  ]}
  layout="bento"
  aspectRatio="5:4"
/>

The **Motherboard** is the main circuit board that connects every hardware component together.

| Function | Description |
|---|---|
| Connection | Connects CPU, RAM and storage |
| Communication | Transfers data through buses |
| Expansion | PCIe and M.2 slots |
| Power | Distributes electrical power |

<Callout kind="tip" title="Exam Tip">
The motherboard is often called the **backbone of the computer** because every major hardware component is connected to it.
</Callout>

### RAM (Random Access Memory)

  query={[

RAM is the **temporary working memory** of a computer.

| Feature | RAM |
|---|---|
| Type | Volatile |
| Data | Temporary |
| Speed | Very Fast |
| Power Off | Data Lost |

<Callout kind="note" title="Remember">
**RAM is volatile memory** — all stored data disappears when power is turned off.
</Callout>

## Hardware vs Software

<Diagram
  type="chain"
  label="Fig 3"

  items={[

    {
      title: "Software",

/>

| Hardware | Software |
|---|---|
| Physical | Logical |
| Tangible | Intangible |
| Manufactured | Programmed |
| CPU, RAM | Windows, Linux |

<Callout kind="warn" title="Difference">
Hardware can be **seen and touched**, while software consists of **instructions** that tell hardware what to do.
</Callout>

## Example

**Question:** Why is the CPU called the brain of the computer?

**Answer:** The CPU controls all operations, processes data, performs calculations and coordinates every hardware component, making it the brain of the computer.
