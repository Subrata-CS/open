# Hardware

<Lede>
Hardware is the **physical part of a computer** that you can see and touch. Every computer system consists of hardware and software working together. This chapter explains every major hardware component from the motherboard to external devices.
</Lede>

## Overview

A computer system contains two main parts:

- **Hardware** → Physical components
- **Software** → Programs and instructions

<Callout kind="def" title="Definition">
**Hardware** is the collection of physical and tangible components of a computer system, including internal parts and external devices.
</Callout>

## Key Concepts

### Internal Hardware

Internal hardware is installed **inside the computer cabinet** and is responsible for processing, memory and storage.

#### Motherboard

The **motherboard** is the main circuit board that connects every hardware component.

<AsyncImageGroup query={["computer motherboard top view","ATX motherboard labeled","desktop motherboard close up"]} layout=bento aspectRatio="5:4"/>

| Function | Description |
|---|---|
| Connects components | CPU, RAM, Storage |
| Data communication | Through buses |
| Expansion | PCIe & M.2 slots |
| Power distribution | Supplies power to devices |

---

#### CPU (Central Processing Unit)

The **CPU** is called the **brain of the computer**.

<AsyncImageGroup query={["modern Intel CPU processor","AMD Ryzen processor close up","CPU installed on motherboard"]} layout=carousel aspectRatio="5:4"/>

**Main Parts**

- Control Unit (CU)
- Arithmetic Logic Unit (ALU)
- Registers

#### RAM (Random Access Memory)

RAM is **temporary memory** used while the computer is running.

<AsyncImageGroup query={["DDR5 RAM memory module","Desktop RAM stick close up","RAM installed on motherboard"]} layout=carousel aspectRatio="5:4"/>

| Feature | RAM |
|---|---|
| Memory Type | Volatile |
| Data | Temporary |
| Speed | Very Fast |
| Power Off | Data Lost |

---

#### ROM (Read Only Memory)

ROM stores permanent startup instructions.

<AsyncImageGroup query={["ROM BIOS chip motherboard","EEPROM chip close up","Computer BIOS firmware chip"]} layout=carousel aspectRatio="5:4"/>

| Feature | ROM |
|---|---|
| Memory Type | Non-volatile |
| Stores | BIOS / Firmware |
| Editable | Very Limited |

---

#### Storage Devices

Storage keeps data permanently.

<AsyncImageGroup query={["Solid state drive SSD","Hard disk drive HDD open","NVMe M.2 SSD module"]} layout=bento aspectRatio="5:4"/>

| Device | Speed | Storage |
|---|---|---|
| HDD | Medium | Large |
| SSD | Fast | Medium–Large |
| NVMe SSD | Very Fast | High |

---

#### Keyboard

#### Mouse

<AsyncImageGroup query={["computer mouse top view","wireless optical mouse","gaming mouse side view"]} layout=carousel aspectRatio="5:4"/>

#### Printer

<AsyncImageGroup query={["laser printer office","inkjet printer color","all in one printer scanner"]} layout=carousel aspectRatio="5:4"/>

## Hardware vs Software

| Hardware | Software |
|---|---|
| Physical | Logical |
| Can be touched | Cannot be touched |
| Manufactured | Programmed |
| Example: CPU | Example: Windows |

<Callout kind="tip" title="Remember">
**Hardware = Body**  
**Software = Brain's Instructions**
</Callout>

## Example

**Question:** Why is RAM called temporary memory?

**Answer:** RAM stores data only while the computer has power. When the power is turned off, all data stored in RAM is lost.
