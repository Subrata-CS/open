# Computer Hardware

<Lede>
Computer hardware is the collection of all physical parts of a computer system. Every device you can touch—from the processor inside the motherboard to the keyboard on your desk—is hardware. Hardware works together with software to perform useful tasks.
</Lede>

---

## What is Computer Hardware?

<Callout kind="def" title="Definition">
**Computer Hardware** is the collection of physical electronic and mechanical components that make up a computer system. Hardware includes both the internal components inside the system unit and the external devices connected to it.
</Callout>

### Real-Life Example

Think of the human body.

| Human Body | Computer Hardware |
|---|---|
| Brain | CPU |
| Memory | RAM |
| Skeleton | Cabinet |
| Eyes | Monitor |
| Hands | Keyboard & Mouse |
| Heart | Power Supply |

Just as the brain controls the human body, the **CPU** controls the computer.

# Internal Hardware

Internal hardware consists of the components located inside the computer cabinet.

## 1. CPU (Central Processing Unit)

<AsyncImageGroup query={["Intel Core i7 processor close up","AMD Ryzen processor top view","CPU installed on motherboard"]} layout=bento aspectRatio="5:4"/>

The **CPU** is known as the **Brain of the Computer** because it performs calculations, logical operations, and executes program instructions.

| Feature | Description |
|---|---|
| Full Name | Central Processing Unit |
| Function | Processes instructions |
| Performs | Arithmetic & Logic |
| Speed | Measured in GHz |
| Example | Intel Core i5, AMD Ryzen 7 |

### Why is CPU called the Brain?

- Executes every instruction
- Controls other hardware
- Performs calculations
- Makes logical decisions

---

## 2. Motherboard

<AsyncImageGroup query={["Desktop computer motherboard top view","Motherboard with labeled components","Gaming motherboard high resolution"]} layout=carousel/>

The **Motherboard** is the main printed circuit board (PCB) that connects every hardware component.

### Main Parts

| Component | Purpose |
|---|---|
| CPU Socket | Holds the processor |
| RAM Slot | Holds memory modules |
| PCIe Slot | Graphics & expansion cards |
| BIOS Chip | Starts the computer |
| Power Connector | Receives electricity |

### Real-Life Example

The motherboard is like the **road network of a city**. Every device communicates through it.

---

## 3. RAM (Random Access Memory)

<AsyncImageGroup query={["DDR4 RAM memory module","Laptop RAM stick","RGB desktop RAM module"]} layout=carousel/>

RAM stores data **temporarily** while programs are running.

<Callout kind="note" title="Important">
RAM is **volatile memory**. All stored data disappears when the computer is powered off.
</Callout>

### Example

When editing a video:

- Video opens into RAM
- CPU processes frames
- After saving, the file moves to SSD

---

## 4. Storage Devices

<AsyncImageGroup query={["Solid state drive SSD","Internal hard disk drive HDD","NVMe M.2 SSD"]} layout=carousel/>

Storage keeps data permanently.

| Device | Speed | Capacity |
|---|---|---|
| HDD | Slow | Very High |
| SSD | Fast | High |
| NVMe SSD | Very Fast | High |

### Comparison

| Feature | HDD | SSD |
|---|---|---|
| Moving Parts | Yes | No |
| Speed | Slow | Fast |
| Noise | Yes | Silent |
| Durability | Lower | Higher |

---

# Python Example

Although hardware is physical, software communicates with hardware. This example simulates hardware information.

```python
hardware = {
    "CPU": "Intel Core i5",
    "RAM": "16 GB",
    "Storage": "512 GB SSD",
    "Monitor": "24 inch LED"
}

for device, value in hardware.items():
    print(device, ":", value)
```

### Output

```text
CPU : Intel Core i5
RAM : 16 GB
Storage : 512 GB SSD
Monitor : 24 inch LED
```

# Interview Questions

### Q1. What is hardware?

Hardware refers to every physical component of a computer that can be touched.

### Q2. What is the difference between RAM and SSD?

RAM stores temporary data, while SSD stores data permanently.

### Q3. Why is the motherboard important?

Because it connects the CPU, RAM, storage, graphics card, and other devices into one working system.
