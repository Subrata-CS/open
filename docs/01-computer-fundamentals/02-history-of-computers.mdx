# History of Computers

<Lede>
The history of computers is the journey from simple calculating tools to today's intelligent AI-powered machines.
</Lede>

![History](/img/computer-history.jpg)

## What is Computer History?

<Callout kind="def" title="Definition">
Computer history is the chronological development of calculating devices and computer systems from ancient times to modern digital computers.
</Callout>

## Evolution Timeline

| Year | Device |
|---|---|
| 2400 BC | Abacus |
| 1617 | Napier's Bones |
| 1642 | Pascaline |
| 1822 | Difference Engine |
| 1837 | Analytical Engine |
| 1944 | Harvard Mark I |
| 1946 | ENIAC |
| Present | AI Computers |

## 1. Abacus

![Abacus](/img/abacus.jpg)

The Abacus was the first known calculating device used for arithmetic operations.

| Feature | Description |
|---|---|
| Type | Manual Calculator |
| Power | No Electricity |
| Use | Addition & Subtraction |

## 2. Napier's Bones

![Napier](/img/napier-bones.jpg)

Invented by **John Napier** in 1617 for multiplication and division.

## 3. Pascaline

![Pascaline](/img/pascaline.jpg)

Invented by **Blaise Pascal** in 1642.

| Feature | Value |
|---|---|
| Technology | Mechanical |
| Inventor | Blaise Pascal |
| Operation | Add & Subtract |

## 4. Difference Engine

![Difference Engine](/img/difference-engine.jpg)

Designed by **Charles Babbage** to generate mathematical tables automatically.

## 5. Analytical Engine

![Analytical Engine](/img/analytical-engine.jpg)

The first design of a programmable computer.

| Analytical Engine | Modern Computer |
|---|---|
| Mill | CPU |
| Store | Memory |
| Punch Card | Input |
| Printer | Output |

## Ada Lovelace

![Ada](/img/ada-lovelace.jpg)

Ada Lovelace wrote the first computer algorithm and is known as the **First Programmer**.

## Harvard Mark I

![Mark I](/img/mark1.jpg)

An electromechanical computer developed in 1944.

## ENIAC

![ENIAC](/img/eniac.jpg)

The first large-scale electronic digital computer.

| Feature | ENIAC |
|---|---|
| Year | 1946 |
| Weight | 30 Tons |
| Vacuum Tubes | 18,000 |
