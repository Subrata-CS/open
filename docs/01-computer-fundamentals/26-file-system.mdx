# File System

## Overview

A **File System** is the method a computer uses to organize, name, store, and retrieve files on a storage device (like an SSD or HDD). Without a file system, a storage drive would just be a giant blob of raw data — the computer wouldn't know where one file ends and another begins, or even what to call them.

Think of a file system like a library's cataloging system. A library doesn't just throw books onto random shelves — every book has a specific location, a label, and an entry in the catalog so it can be found again instantly. A file system does the same thing for your data: it keeps track of exactly where each file is physically stored on the drive, along with its name, size, and folder location.

Different operating systems use different file systems — for example, Windows commonly uses **NTFS**, macOS uses **APFS**, and Linux often uses **ext4** — but they all serve the same basic purpose.

## Key Concepts

- **File** — A named collection of data stored on a device, such as a document, photo, or program.
- **Folder/Directory** — A container used to organize files into groups, and folders can contain other folders too, forming a tree-like structure.
- **File Path** — The exact "address" of a file, showing which folders you'd need to go through to reach it, like `C:\Users\John\Documents\notes.txt`.
- **File Extension** — The part of a filename after the dot (like `.docx`, `.mp3`, `.jpg`) that tells the computer what type of file it is and which program should open it.
- **File Allocation Table / Index** — A behind-the-scenes record the file system keeps, tracking exactly where each file's data physically sits on the storage drive.
- **Common File Systems** — NTFS (Windows), APFS (macOS), ext4 (Linux), and FAT32/exFAT (widely compatible, often used for USB drives).
