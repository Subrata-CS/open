# Input and Output

## Overview

**Input and Output (I/O)** devices are how a computer talks with the outside world — with you. **Input devices** send information *into* the computer (like typing on a keyboard). **Output devices** send information *out of* the computer, back to you (like showing text on a screen).

Imagine a simple conversation:
- 👂 **Input** = You speaking to a friend (information going in)
- 🧠 **Processing** = Your friend thinking about what you said
- 👄 **Output** = Your friend replying back (information coming out)

A computer works exactly the same way — every single thing you do on a computer follows this same 3-step pattern.

## Key Concepts

- **Input Devices** — Send data into the computer. Examples: keyboard, mouse, microphone, scanner, webcam.
- **Output Devices** — Show or send data out from the computer. Examples: monitor, speakers, printer.
- **Both Input and Output** — Some devices do both, like a touchscreen (you touch it = input, it shows things = output).
- **CPU's Role** — Sits in the middle, processing whatever comes in from input, before sending a result out to output.
- **Ports** — Physical connectors (USB, HDMI, audio jack) that link these devices to the motherboard.
