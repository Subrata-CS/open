# Cache Memory

## Overview

**Cache Memory** is a small, extremely fast type of memory located very close to the CPU — sometimes even built directly inside it. Its job is to store copies of data and instructions that the CPU uses frequently, so the CPU doesn't have to wait for the much slower RAM every single time.

Think of cache like a small notepad you keep on your desk while working, next to a large bookshelf (RAM) across the room. Instead of walking to the bookshelf every time you need information, you jot down the most commonly used facts on the notepad. This saves time, because reaching for the notepad is much faster than getting up and walking to the shelf every time.

Cache memory is much smaller in size than RAM, but it's significantly faster, which is exactly why it's used only for the data the CPU needs right now or is likely to need very soon.

## Key Concepts

- **Speed** — Cache memory is much faster than RAM, though also much smaller in size and more expensive per byte.
- **Proximity to CPU** — Cache is located physically closer to the CPU (often inside the CPU chip itself), which reduces the time it takes to access data.
- **Cache Levels (L1, L2, L3)** — Cache is usually organized in levels: **L1** is the smallest and fastest (closest to the CPU core), **L2** is larger but slightly slower, and **L3** is the largest and shared across multiple cores.
- **Cache Hit** — When the CPU finds the data it needs already in the cache, saving time by avoiding a trip to RAM.
- **Cache Miss** — When the data isn't in the cache, forcing the CPU to fetch it from the slower RAM instead.
- **Locality of Reference** — The principle that programs tend to reuse the same data and instructions repeatedly, which is why caching recently used data is so effective.
