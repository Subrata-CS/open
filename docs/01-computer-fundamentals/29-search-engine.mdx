# Search Engine

## Overview

A **Search Engine** is a service (like Google, Bing, or DuckDuckGo) that helps you find information on the internet without needing to already know a website's exact address. You type in a few words describing what you're looking for, and the search engine instantly returns a ranked list of relevant websites.

Think of a search engine as a librarian for the entire internet. There are billions of webpages out there — far too many for any person to browse manually. A search engine has already "read" and organized an enormous portion of the internet ahead of time, so when you ask a question, it can instantly point you to the most relevant, useful pages, ranked by how well they match what you're looking for.

Search engines are different from web browsers: a **browser** (like Chrome) is the software you use to view any website, while a **search engine** (like Google) is just one particular website you visit through your browser to help you find other websites.

## Key Concepts

- **Crawling** — Search engines use automated programs called **crawlers** (or "spiders") that constantly scan the internet, visiting webpages and following links to discover new content.
- **Indexing** — After crawling a page, the search engine stores and organizes its content in a massive database (the "index"), similar to a library catalog, so it can be retrieved quickly later.
- **Ranking Algorithm** — When you search, the engine doesn't just find matching pages — it ranks them using complex algorithms that consider relevance, popularity, and trustworthiness, showing the best results first.
- **Keywords** — The words you type into the search bar, which the search engine matches against its index to find related pages.
- **SEO (Search Engine Optimization)** — Techniques website owners use to help their pages rank higher in search results, by making content more relevant and easier for crawlers to understand.
- **Search Results Page (SERP)** — The page showing your search results, typically including links, brief descriptions, and sometimes direct answers, ads, or images.
