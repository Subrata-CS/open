# Keyboard

## Overview

The **Keyboard** is the most common **input device** used to type text, numbers, and commands into a computer. Every letter you type, every password you enter, every game control you press — it all starts with the keyboard sending signals to the computer.

Think of the keyboard as a set of buttons, where each button (key) tells the computer "this specific character or command was pressed." The computer then figures out what that means and responds — whether that's showing a letter on screen, moving a game character, or triggering a shortcut like copy-paste.

A standard keyboard has around 104 keys, including letters, numbers, symbols, and special function keys.

## Key Concepts

- **Alphanumeric Keys** — Letter keys (A–Z) and number keys (0–9), used for typing text and numbers.
- **Function Keys (F1–F12)** — Special keys at the top of the keyboard used for shortcuts, like F5 to refresh a page or F11 for full screen.
- **Modifier Keys** — Keys like Shift, Ctrl, Alt, and Windows/Command key, which change what other keys do when pressed together (e.g., Ctrl + C for copy).
- **Navigation Keys** — Arrow keys, Home, End, Page Up/Down — used to move the cursor or scroll through content.
- **Keycode/Scan Code** — Every key press sends a unique code to the computer, which the operating system translates into the actual character or action.
- **Keyboard Types** — Includes mechanical keyboards (physical switches under each key, tactile feel), membrane keyboards (softer, quieter, common on laptops), and virtual/on-screen keyboards (touchscreens).
