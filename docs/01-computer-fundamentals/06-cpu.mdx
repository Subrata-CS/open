# CPU

## Overview

The **CPU (Central Processing Unit)** is often called the **"brain"** of the computer. Every task the computer performs — calculations, decisions, running programs — is controlled and processed by the CPU.

For example, when we run a program — say a calculator app adding 5 + 3 — it is the CPU that actually performs the addition and tells the screen what to display. In short, every instruction in a computer passes through and is executed by the CPU.

Physically, the CPU is a small chip mounted on the motherboard. Even though it's small in size, it contains billions of transistors working together to perform all the calculations and logic operations.

## Key Concepts

- **ALU (Arithmetic Logic Unit)** — The part of the CPU that performs mathematical operations (add, subtract, multiply, divide) and logical operations (AND, OR, NOT).
- **CU (Control Unit)** — The part of the CPU that decides which instruction should run when, and coordinates the other parts of the computer (memory, input/output devices) with proper instructions.
- **Registers** — Very small but extremely fast memory locations inside the CPU, used to temporarily hold data the CPU is currently working with.
- **Cache Memory** — A small, high-speed memory located close to the CPU, storing frequently used data so the CPU doesn't have to fetch it from the slower RAM every time.
- **Clock Speed (GHz)** — Measures how many cycles (steps) the CPU can perform per second. For example, 3 GHz means 3 billion cycles per second.
- **Core** — A single CPU can have multiple "cores," where each core can work on a different task at the same time (Multi-core processor).
- **Fetch–Decode–Execute Cycle** — The basic cycle that describes how the CPU works:
  1. **Fetch** — Get the next instruction from memory.
  2. **Decode** — Understand what the instruction means (what needs to be done).
  3. **Execute** — Carry out the instruction.
