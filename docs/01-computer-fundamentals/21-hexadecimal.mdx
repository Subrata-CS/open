# Hexadecimal

## Overview

The **Hexadecimal system** (also called **base 16**, or just "hex") is a number system that uses **16 symbols**: 0–9, followed by the letters A, B, C, D, E, F — where A=10, B=11, C=12, D=13, E=14, and F=15.

Hex exists for the same reason octal does — it's a convenient shorthand for binary. Since 16 is a power of 2 (2⁴ = 16), each single hex digit maps neatly to exactly **4 binary bits**. This makes hexadecimal even more compact than octal, and it's why hex is the most commonly used shorthand in modern programming — much shorter and easier to read than long strings of 0s and 1s.

You've likely already seen hexadecimal without realizing it — website color codes like `#FF5733`, memory addresses in programming, and MAC addresses on network devices are all written in hexadecimal.

## Key Concepts

- **Base 16** — Hexadecimal uses 16 unique symbols (0–9, A–F), with each position representing a power of 16.
- **4-Bit Grouping** — Every single hex digit corresponds to exactly 4 binary bits, since 2⁴ = 16. This makes converting between binary and hex extremely fast.
- **Letters as Digits** — Since decimal only has 10 digits (0–9), hex borrows letters A–F to represent the values 10 through 15.
- **Color Codes** — Web and design colors are often written in hex, like `#FF0000` for red, where each pair of hex digits represents the amount of red, green, and blue.
- **Memory Addresses** — Programmers often see hexadecimal when looking at memory addresses or debugging code, since it's a compact way to represent binary data.
- **Hexadecimal to Decimal Conversion** — Like other number systems, you convert hex to decimal by multiplying each digit by its place value (powers of 16) and adding them up.

## Example — Watch It Happen Step by Step

Let's convert the hexadecimal number **1A** into decimal using Python.

```python
hex_number = "1A"
decimal_value = int(hex_number, 16)
print(decimal_value)  # Output: 26
```
