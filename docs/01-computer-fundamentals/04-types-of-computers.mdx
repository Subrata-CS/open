# Types of Computers

<Lede>
Computers are classified in different ways depending on **size**, **purpose**, and the **type of data** they process. Understanding these classifications is essential because different computers are designed for different real-world tasks.
</Lede>

## Overview

A **computer** is not a single type of machine. A smartwatch, a laptop, a banking server, and a weather forecasting supercomputer are all computers, but they belong to different categories.

<Callout kind="def" title="Definition">
**Types of computers** are the different categories of computers classified according to their size, processing capability, purpose, and the kind of data they handle.
</Callout>

## 1. Supercomputer

<Fig
  label="Fig 3"
  title="Supercomputer"
  caption="Supercomputers perform trillions of calculations every second using thousands of processors working together."
>
  <AsyncImageGroup query={["Frontier supercomputer data center","PARAM Siddhi AI supercomputer India","Supercomputer server rows"]} layout=carousel/>
</Fig>

A **supercomputer** is the fastest and most powerful type of computer. It is designed for extremely complex scientific and engineering calculations.

#### Characteristics

| Feature | Description |
|---|---|
| Users | Multiple researchers |
| Speed | Extremely high |
| Processors | Thousands |
| Cost | Very expensive |
| Size | Large data center |

#### Applications

- Weather forecasting
- Climate modelling
- Space research
- Nuclear simulation
- Artificial Intelligence training

**Examples:** Frontier, PARAM Siddhi-AI, Fugaku

<Callout kind="tip" title="Exam Fact">
**PARAM** is India's famous series of supercomputers developed by **C-DAC**.
</Callout>

- Railway reservation
- Insurance

- Airline booking

## 3. Minicomputer

<Fig
  label="Fig 5"
  title="Minicomputer"

  <AsyncImageGroup query={["Minicomputer server rack","DEC PDP minicomputer historical","Department server room"]} layout=carousel/>

A **minicomputer** is a medium-sized multi-user computer positioned between a mainframe and a microcomputer.

#### Features

- Supports dozens of users
- Smaller than mainframe
- Used as servers
- Moderate processing power

#### Applications

- Schools
- Laboratories
- Small industries
- Departmental databases

## 4. Microcomputer

<Fig
  label="Fig 6"
  title="Microcomputer"

Almost every computer used in homes, schools and offices is a **microcomputer**.

## Hybrid Computer

<Fig
  label="Fig 11"
  title="Hybrid computer"
  caption="Hybrid computers combine analog measurement with digital processing, making them ideal for medical and industrial systems."
>
  <AsyncImageGroup query={["ICU patient monitoring system","Petrol pump digital analog system","Hospital ECG monitoring equipment"]} layout=carousel/>

A **hybrid computer** combines the features of **analog** and **digital** computers.

#### Applications

- ICU monitoring
- ECG machine
- Petrol pump
- Aircraft control
- Industrial automation

<Callout kind="tip" title="Memory Trick">
**AHD**

- **A** = Analog → Continuous
- **H** = Hybrid → Both
- **D** = Digital → Binary
</Callout>

# Example

Suppose an exam asks:

**Why is a laptop called a microcomputer?**

**Answer:**

> A laptop is called a microcomputer because it is designed for a single user and uses a single microprocessor as its CPU. It is compact, affordable and suitable for general-purpose computing.
