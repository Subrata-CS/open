# Binary

## Overview

**Binary** is the number system that computers actually use internally. It only has two symbols: **0** and **1**. Every single thing a computer does — every letter you type, every photo you see, every song you play — is, deep down, stored and processed as a long sequence of 0s and 1s.

Why only two symbols? Because a computer's hardware is built from tiny electronic switches (transistors) that can only be in one of two states: **off** (0) or **on** (1) — like a light switch that's either off or on, with nothing in between. Binary is simply the mathematical way of representing these two electrical states.

Each single 0 or 1 is called a **bit** (short for "binary digit") — the smallest possible unit of data a computer can store.

## Key Concepts

- **Bit** — A single binary digit, either 0 or 1. It's the smallest unit of data in computing.
- **Byte** — A group of 8 bits. One byte can represent 256 different values (from 00000000 to 11111111), and is often used to represent a single character, like the letter "A".
- **Binary Place Values** — Just like decimal has place values (1s, 10s, 100s), binary has place values based on powers of 2 (1, 2, 4, 8, 16...). Each position in a binary number represents a power of 2.
- **On/Off Representation** — Each bit maps directly to an electrical signal: 1 means a circuit is "on" (current flowing), 0 means it's "off" (no current).
- **Binary to Decimal Conversion** — To convert binary to decimal, you add up the place values where there's a 1. For example, 1011 = (1×8) + (0×4) + (1×2) + (1×1) = 11.
- **Why Computers Use Binary** — Binary is reliable and simple for hardware to detect (just on or off), making it far less error-prone than trying to detect many different voltage levels for a base-10 system.
