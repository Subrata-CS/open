# System Basics

## Overview

A **Computer System** is the complete combination of parts that work together to let you use a computer — not just the physical device, but everything that makes it actually function. A system is made up of two main halves: **Hardware** (the physical parts you can touch, like the CPU, RAM, and monitor) and **Software** (the programs and instructions that tell the hardware what to do).

Neither half is useful alone. Hardware without software is just an expensive collection of metal and plastic — it has no idea what to do. Software without hardware has nothing to actually run on — it's just code sitting nowhere. A computer system only comes alive when hardware and software work together.

Think of it like a body and a mind: hardware is the body (physical, able to act), and software is the mind (giving instructions and decisions). Together, they form a working "person" — or in this case, a working computer.

## Key Concepts

- **Hardware** — The physical, touchable components of a computer, such as the CPU, RAM, storage, motherboard, keyboard, and monitor.
- **Software** — The set of instructions or programs that tell hardware what to do. Software itself is intangible — you can't physically touch a program, only interact with it.
- **System Software** — Software that manages the computer itself, such as the **Operating System** (Windows, macOS, Linux), which controls hardware and lets other programs run.
- **Application Software** — Software designed for specific user tasks, like a web browser, word processor, or game — these run "on top of" the operating system.
- **Operating System (OS)** — The most important piece of system software; it acts as a middleman between hardware and all other software, managing memory, files, and hardware resources.
- **Boot Process** — The sequence of steps a computer follows from power-on to having a fully working system ready for you to use (covered in more detail separately).
