# UEFI

## Overview

**UEFI (Unified Extensible Firmware Interface)** is the modern replacement for traditional BIOS. It does the same core job — running first when you power on the computer, checking hardware, and starting the boot process — but it's faster, more capable, and easier to use than old-style BIOS.

Think of UEFI as BIOS's smarter, more advanced successor. Where BIOS was like a simple text-based checklist from the 1980s, UEFI is like a modern app with a mouse-clickable graphical menu, support for larger storage drives, faster startup times, and better built-in security features.

Almost all computers made in the last decade use UEFI instead of traditional BIOS, though many people still casually call it "BIOS" out of habit, even when their system is technically running UEFI.

## Key Concepts

- **Successor to BIOS** — UEFI performs the same essential startup role as BIOS, but with modern improvements in speed, security, and usability.
- **Graphical Interface** — Unlike old BIOS (text-only, keyboard-controlled), UEFI often supports mouse input and graphical menus, making settings easier to navigate.
- **Faster Boot Times** — UEFI can initialize hardware and hand off to the operating system more quickly than legacy BIOS.
- **Secure Boot** — A security feature in UEFI that checks whether the operating system's startup software is trusted and unmodified, helping protect against malware that tries to load before the OS.
- **Support for Large Drives** — UEFI supports the GPT (GUID Partition Table) disk format, allowing computers to use storage drives larger than 2TB — something older BIOS with MBR partitioning couldn't handle.
- **Backward Compatibility** — Many UEFI systems include a "Legacy BIOS mode" or "CSM" to still support older operating systems and hardware that expect traditional BIOS behavior.
