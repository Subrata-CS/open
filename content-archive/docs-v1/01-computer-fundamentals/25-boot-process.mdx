# Boot Process

## Overview

The **Boot Process** is the complete sequence of steps a computer follows from the moment you press the power button, to the moment you see a fully working desktop, ready to use. It brings together everything we've learned so far — BIOS/UEFI, RAM, storage, and the operating system — all working in a precise order.

Think of the boot process like waking up in the morning: first your body starts functioning (heartbeat, breathing — like BIOS/UEFI checking hardware), then you slowly become aware of your surroundings (like the OS loading into RAM), and finally you're fully awake and ready to start your day (like reaching the desktop, ready for use).

Every single time you turn on a computer, this exact sequence repeats — it's one of the most fundamental processes in computing, even though it usually only takes a few seconds.

## Key Concepts

- **Power-On** — The very first step: electricity flows into the motherboard the instant you press the power button.
- **POST (Power-On Self-Test)** — Performed by BIOS/UEFI, this checks that essential hardware (CPU, RAM, storage) is present and functioning correctly.
- **Bootloader** — A small program, stored on the storage drive, whose only job is to locate and start loading the operating system into RAM.
- **Kernel Loading** — The core part of the operating system (the "kernel") loads into RAM and starts managing hardware, memory, and running processes.
- **Login/Desktop** — Once the OS finishes loading, you're presented with a login screen (if applicable) and then the desktop — the computer is now fully ready for use.
- **Cold Boot vs Warm Boot** — A cold boot starts from completely powered off; a warm boot (restart) skips some hardware checks since the system was already partially running.
