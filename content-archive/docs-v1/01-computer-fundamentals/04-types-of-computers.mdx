# Types of Computers

<Lede>
A smartwatch, a laptop, a bank's transaction server and a machine that forecasts
the monsoon are all computers. Calling them all "computers" is true but useless,
so we sort them three different ways — by size, by purpose, and by the kind of
data they handle. The trick this topic teaches is that these three schemes run
at the same time: every machine has an answer in all three.
</Lede>

## Overview

<Callout kind="def" title="Definition">
  Types of computers are the categories into which computers are grouped
  according to their size and processing capacity, the purpose they are built
  for, and the kind of data they process.
</Callout>

<Callout kind="tip" title="Exam tip">
  The question always names the basis: "classify computers **on the basis of
  size**". Answer within that basis only. A laptop is a microcomputer by size, a
  general-purpose computer by purpose, and a digital computer by data — all
  three at once, and each is the right answer to a different question.
</Callout>

## Classification by size

Size here means processing capacity, not physical bulk. The four classes differ
in how many users they serve at once and how much work they get through.

### Supercomputer

The fastest class of machine, built from thousands of processors working on
parts of the same problem at the same time — **parallel processing**. Speed is
measured in FLOPS, floating-point operations per second:

<Eq block>{String.raw`1\;\text{petaflop} = 10^{15}\ \text{operations per second}`}</Eq>

| Feature | Detail |
| --- | --- |
| **Users** | A research team, through submitted jobs — nobody sits at it |
| **Processors** | Thousands, running in parallel |
| **Cost** | Crores of rupees, plus the building and cooling |
| **Used for** | Weather forecasting, climate models, nuclear simulation, drug and genome research, training AI models |
| **Examples** | Frontier, Fugaku, and India's PARAM series and PARAM Siddhi-AI |

<Callout kind="tip" title="Exam fact">
  India's supercomputers belong to the **PARAM** series, developed by **C-DAC**,
  which began with PARAM 8000 in 1991 under Dr Vijay Bhatkar.
</Callout>

### Mainframe computer

A mainframe is not built for raw speed but for **volume and reliability** — it
handles millions of small transactions a day, for thousands of users, without
stopping. Banks run for decades on the same mainframe.

| Feature | Detail |
| --- | --- |
| **Users** | Thousands, at terminals, simultaneously |
| **Strength** | Uptime, security, huge input and output throughput |
| **Used for** | Banking, railway reservation, insurance claims, census, airline booking |
| **Example** | The IBM Z series |

### Minicomputer

Mid-sized, serving a department rather than a whole organisation. The class
began with machines like the DEC PDP-8; today the same role is filled by what we
simply call a **server**.

| Feature | Detail |
| --- | --- |
| **Users** | Dozens at a time |
| **Used for** | College labs, small industries, departmental databases, web servers |
| **Position** | Between a mainframe and a microcomputer |

### Microcomputer

Any computer built around a **single microprocessor** and used by one person at
a time. This is the class the fourth generation created, and the one nearly
everybody actually touches.

| Feature | Detail |
| --- | --- |
| **Users** | One |
| **Processor** | A single microprocessor as CPU |
| **Examples** | Desktop, laptop, tablet, smartphone, Chromebook, workstation |
| **Cost** | Affordable enough for personal ownership |

### Side by side

| Type | Users at once | Processing power | Typical owner | Example |
| --- | --- | --- | --- | --- |
| **Supercomputer** | A research queue | Highest | A country or national lab | PARAM Siddhi-AI |
| **Mainframe** | Thousands | Very high, transaction-heavy | A bank or railway | IBM Z |
| **Minicomputer** | Dozens | Medium | A department or college | Departmental server |
| **Microcomputer** | One | Moderate | A person | Laptop, smartphone |

<Callout kind="warn" title="Careless-mistake trap">
  A supercomputer is fastest at **one huge calculation**; a mainframe is best at
  **millions of small transactions**. Weather forecasting goes to the
  supercomputer, railway booking to the mainframe. Swapping those two is the
  most common error in this topic.
</Callout>

## Classification by purpose

<Diagram
  type="chain"
  label="Fig 3"
  title="What the machine was built to do"
  caption="Change the software and a general-purpose machine changes jobs. A special-purpose machine cannot."
  items={[
    {
      title: 'GENERAL PURPOSE',
      lines: ['runs any program you install', 'laptop, desktop, tablet'],
      highlight: true,
    },
    {
      title: 'SPECIAL PURPOSE',
      lines: ['built for one job only', 'ATM, traffic signal, ECG'],
    },
  ]}
/>

A **general-purpose** computer stores its instructions in memory, so loading a
different program gives it a different job — the same laptop writes an essay,
edits a photo and plays a game. A **special-purpose** computer has its program
fixed in a chip when it is manufactured, which makes it cheaper, smaller and
more reliable at that one task.

| Special-purpose device | The one job it does |
| --- | --- |
| **ATM** | Dispenses cash and records the transaction |
| **Traffic signal controller** | Times the lights at a junction |
| **Washing machine board** | Runs the wash cycle |
| **ECG machine** | Records and prints heart activity |
| **Car engine control unit** | Regulates fuel and ignition |

<Callout kind="note" title="Embedded computer">
  A special-purpose computer built into a larger machine is called an
  **embedded computer** or embedded system. Your washing machine, microwave and
  car all contain one, which is why there are far more computers in a house than
  there are screens.
</Callout>

## Classification by the data handled

<Diagram
  type="chain"
  label="Fig 4"
  title="Measuring, counting, or both"
  eyebrow="ANALOG · DIGITAL · HYBRID"
  caption="Analog measures a quantity that flows; digital counts in discrete steps; hybrid measures first and then counts."
  items={[
    { title: 'ANALOG', lines: ['continuous physical values', 'speedometer, thermometer'] },
    { title: 'DIGITAL', lines: ['discrete binary digits', 'laptop, phone, calculator'], highlight: true },
    { title: 'HYBRID', lines: ['measures, then digitises', 'ICU monitor, petrol pump'] },
  ]}
/>

An **analog computer** works with quantities that vary continuously — voltage,
pressure, speed, temperature. It does not count; it measures, and its output is
a needle position or a continuous trace. It is fast but limited in accuracy.

A **digital computer** works only with 0 and 1. Everything — text, sound, images
— is first converted into binary. This gives very high accuracy, unlimited
storage and the ability to be reprogrammed, which is why every computer you own
is digital.

A **hybrid computer** does both: an analog front end measures a real-world
quantity, and a digital back end processes and displays it. In an ICU monitor,
the sensors read the patient's heartbeat as a continuous signal; the computer
converts it and shows a number the nurse can read.

| Feature | Analog | Digital | Hybrid |
| --- | --- | --- | --- |
| **Data** | Continuous physical quantities | Discrete binary digits | Both |
| **Operation** | Measures | Counts | Measures, then counts |
| **Accuracy** | Limited | Very high | High |
| **Storage** | Very little | Very large | Large |
| **Output** | A needle, dial or trace | Numbers and text on screen | Both |
| **Example** | Speedometer, mercury thermometer | Laptop, smartphone | ICU monitor, petrol pump |

<Callout kind="tip" title="Memory trick — A, D, H">
  **A**nalog **A**pproximates a flowing quantity. **D**igital counts in
  **D**igits. **H**ybrid does **b**oth halves.
</Callout>

### One machine, three answers

| Device | By size | By purpose | By data |
| --- | --- | --- | --- |
| **Laptop** | Microcomputer | General purpose | Digital |
| **ATM** | Microcomputer | Special purpose | Digital |
| **Railway reservation server** | Mainframe | Special purpose | Digital |
| **ICU patient monitor** | Microcomputer | Special purpose | Hybrid |
| **Weather forecasting machine** | Supercomputer | Special purpose | Digital |
| **Analog speedometer** | Not applicable | Special purpose | Analog |

## Example

The classification is really three questions asked about the same machine. Here
that is written out as a function, which is the clearest way to see that the
three answers are independent of each other.

```python
# 1. INPUT — one machine, described by three facts
def classify(users, fixed_job, data_kind):
    # by size
    if users > 1000:
        size = "Mainframe or supercomputer"
    elif users > 1:
        size = "Minicomputer / server"
    else:
        size = "Microcomputer"

    # by purpose
    purpose = "Special purpose" if fixed_job else "General purpose"

    # by data
    return size, purpose, data_kind.title()


# 2. PROCESS and 3. OUTPUT
laptop = classify(users=1, fixed_job=False, data_kind="digital")
monitor = classify(users=1, fixed_job=True, data_kind="hybrid")

print("Laptop      :", laptop)
print("ICU monitor :", monitor)
```

Expected output:

```text
Laptop      : ('Microcomputer', 'General purpose', 'Digital')
ICU monitor : ('Microcomputer', 'Special purpose', 'Hybrid')
```

Both are microcomputers. They differ on the other two questions — which is the
whole point of having three classifications instead of one.
