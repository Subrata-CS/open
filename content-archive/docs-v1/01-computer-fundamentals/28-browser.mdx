# Browser

## Overview

A **Web Browser** is the software you use to access and view websites on the internet — examples include Chrome, Firefox, Safari, and Edge. It's your window into the World Wide Web: you type an address or search for something, and the browser fetches that content from a server and displays it on your screen in a readable, clickable format.

Think of a browser as a translator and delivery person combined. Websites are actually stored as raw code (HTML, CSS, JavaScript) — a jumble of text instructions that would look meaningless if you opened it directly. The browser's job is to fetch that code from the server, "translate" it, and instantly turn it into the nicely formatted pages, images, and buttons you see and interact with.

Without a browser, the internet's content would still exist on servers, but you'd have no easy way to actually see or use it — the browser is what makes the web usable for everyday people.

## Key Concepts

- **URL (Uniform Resource Locator)** — The web address you type in, like `https://www.example.com`, telling the browser exactly which page to fetch.
- **HTML, CSS, JavaScript** — The core building blocks of a webpage: HTML provides structure/content, CSS handles styling/design, and JavaScript adds interactivity.
- **Rendering** — The process where the browser takes the raw HTML/CSS/JavaScript code and converts it into the visual page you see on screen.
- **Tabs** — Modern browsers let you open multiple websites at once, each in its own tab, so you can switch between them easily.
- **Cache** — Browsers temporarily save parts of websites you've visited (images, files) so they load faster the next time you visit.
- **Search Engine** — A separate service (like Google) that the browser can use to help you find websites when you don't already know the exact URL.
