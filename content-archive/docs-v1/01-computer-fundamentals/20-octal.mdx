# Octal

## Overview

The **Octal system** (also called **base 8**) is a number system that uses exactly **8 digits**: 0, 1, 2, 3, 4, 5, 6, 7. Notice there's no 8 or 9 — once you reach 7 and need to go higher, you carry over to the next position, just like decimal carries over after 9.

Octal isn't something we use in everyday life, but it played an important historical role in computing. Because 8 is a power of 2 (2³ = 8), each octal digit maps neatly to exactly **3 binary bits**. This made octal a convenient shorthand for programmers in the early days of computing — writing long binary numbers was error-prone, so octal offered a shorter, easier-to-read alternative that still translated cleanly to binary.

Today, octal is used less often than hexadecimal, but it still appears in specific areas like Unix/Linux file permission codes (e.g., `chmod 755`).

## Key Concepts

- **Base 8** — Octal uses 8 unique digits (0–7), with each position representing a power of 8.
- **3-Bit Grouping** — Every single octal digit corresponds to exactly 3 binary bits, since 2³ = 8. This makes converting between binary and octal very fast.
- **No 8 or 9** — Since octal only goes up to 7, the number "8" in decimal is written as "10" in octal (just like how decimal "10" comes after single digit 9).
- **Historical Use** — Older computer systems and early programming languages used octal as a more compact way to represent binary machine code.
- **File Permissions** — In Unix/Linux systems, file permissions are often written in octal, such as `755`, where each digit represents read/write/execute permissions for owner, group, and others.
- **Octal to Decimal Conversion** — Like other number systems, octal numbers can be converted to decimal by multiplying each digit by its place value (powers of 8) and adding them up.

```python
print(decimal_value)  # Output: 15
```
