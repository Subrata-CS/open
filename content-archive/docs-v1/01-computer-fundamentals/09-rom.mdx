# ROM

## Overview

**ROM (Read Only Memory)** is a type of memory that permanently stores data, even when the computer is turned off. Unlike RAM, which loses everything when power is cut, ROM keeps its data safe no matter what — this is why it's called **non-volatile memory**.

ROM usually stores the most basic, critical instructions a computer needs — like the **firmware (BIOS/UEFI)** that runs the moment you turn the computer on, before the operating system even loads. Think of ROM as a small instruction manual permanently glued inside the computer: you can read it anytime, but under normal use, you can't easily change or erase what's written in it.

Physically, ROM is usually a small chip on the motherboard, much smaller in capacity than RAM or storage, because it only needs to hold a small set of essential startup instructions.

## Key Concepts

- **Non-Volatile Memory** — ROM keeps its data permanently, even when the computer is powered off, unlike RAM which is volatile.
- **Read Only** — Under normal operation, data in ROM cannot be modified or deleted by regular programs, protecting critical startup instructions from being accidentally changed.
- **Firmware** — The software permanently stored in ROM, such as BIOS/UEFI, which controls the earliest stage of the computer's startup process.
- **ROM vs RAM** — ROM is non-volatile and mainly read-only; RAM is volatile and can be read from and written to constantly during normal use.
- **Types of ROM** — Includes variations like **PROM** (Programmable ROM), **EPROM** (Erasable Programmable ROM), and **EEPROM** (Electrically Erasable Programmable ROM), which allow limited, controlled ways to update the stored data.
- **Boot Process Role** — ROM holds the very first instructions the CPU executes when the computer powers on, before handing control over to the operating system.

## Example

Let's understand this with a simple analogy instead of code, since ROM is best understood through the startup process.

**Imagine turning on your computer:**

1. You press the power button — electricity reaches the motherboard.
2. The CPU's very first instructions come from **ROM**, specifically the firmware (BIOS/UEFI) stored there.
3. This firmware performs a quick hardware check, called **POST (Power-On Self-Test)**, making sure the CPU, RAM, and storage are all working properly.
4. Once the check passes, the firmware in ROM locates the operating system on the storage drive and loads it into **RAM**.
5. From this point on, the operating system takes control, and ROM's job is done until the next time you restart the computer.

Because ROM's instructions rarely need to change, and must always be available even after a power loss, storing them in non-volatile ROM (instead of volatile RAM) ensures the computer can always start up reliably.
