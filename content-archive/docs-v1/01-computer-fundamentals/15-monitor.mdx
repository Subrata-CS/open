# Monitor

## Overview

The **Monitor** is the most important **output device** of a computer — it's the screen that shows you everything: text, images, videos, and the entire graphical interface you interact with. Without a monitor, you'd have no way of actually *seeing* what the computer is doing.

Think of the monitor as a window into the computer's "mind." Every calculation, every keystroke you type, every file you open — the CPU processes it, and the monitor is what turns that invisible processing into something you can actually see with your eyes.

A monitor doesn't do any "thinking" itself — it simply displays whatever visual data the CPU (through the graphics card) sends to it, refreshing many times per second to keep the image smooth and up to date.

## Key Concepts

- **Pixels** — The tiny individual dots of light that make up everything shown on screen. Millions of pixels together form the full picture.
- **Resolution** — The number of pixels on screen, usually written as width × height (e.g., 1920×1080). Higher resolution means sharper, more detailed images.
- **Refresh Rate (Hz)** — How many times per second the screen updates the image. A 60Hz monitor refreshes 60 times per second; higher refresh rates (120Hz, 144Hz) look smoother, especially for fast motion like games.
- **GPU (Graphics Processing Unit)** — A specialized chip that prepares the visual data before sending it to the monitor. It works closely with the CPU but focuses specifically on images and graphics.
- **Display Types** — Includes LCD, LED, and OLED — different technologies for how the screen produces light and color.
- **Ports** — Monitors connect to the computer via cables like HDMI, DisplayPort, or VGA, which carry the visual signal from the graphics card to the screen.
