# What is a Computer?

<Callout kind="def" title="Definition">
A computer is an electronic device that accepts **input**, processes it according to stored instructions, stores data when necessary, and produces useful **output**.
</Callout>

### Simple Definition

A computer performs four basic operations:

1. Input
2. Processing
3. Storage
4. Output

---

# Real-Life Example

Imagine withdrawing money from an ATM.

| Step | Computer | ATM Example |
|---|---|---|
| Input | Data entered | Insert ATM card |
| Processing | CPU verifies PIN | Bank checks account |
| Storage | Database | Account balance |
| Output | Information | Cash & Receipt |

Every computer system follows this workflow.

# Characteristics of a Computer

A computer has several unique characteristics that make it useful.

### 1. Speed

A modern processor performs **billions of operations every second**.

### 2. Accuracy

Computers produce highly accurate results when instructions are correct.

### 3. Automation

Once a program starts, the computer works automatically.

### 4. Storage

Large amounts of data can be stored permanently.

### 5. Reliability

Computers can perform repetitive tasks without getting tired.

### 6. Multitasking

One computer can run multiple applications simultaneously.
