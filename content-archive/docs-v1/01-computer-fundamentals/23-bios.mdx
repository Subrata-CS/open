# BIOS

## Overview

**BIOS (Basic Input/Output System)** is a small piece of firmware stored on the motherboard that runs the very first moment you turn on a computer — even before the operating system starts loading. Its job is to check that all the essential hardware (CPU, RAM, storage, keyboard) is present and working, and then hand control over to the operating system.

Think of BIOS as a strict security guard at the entrance of a building, doing a quick checklist before letting anyone in: "Is the CPU here? Yes. Is RAM connected? Yes. Is there a storage device to boot from? Yes." Only after this checklist passes does BIOS "open the door" and let the operating system start running.

BIOS is considered **firmware** — a special type of software permanently stored in a chip on the motherboard, not on your hard drive or SSD like normal programs.

## Key Concepts

- **Firmware** — Software that is permanently or semi-permanently stored in hardware (like a chip on the motherboard), rather than on the main storage drive.
- **POST (Power-On Self-Test)** — The hardware checklist BIOS runs immediately at startup, verifying the CPU, RAM, storage, and other essential components are functioning.
- **Boot Device Selection** — BIOS decides which storage device to load the operating system from (e.g., your main SSD, or a USB drive if you're reinstalling an OS).
- **BIOS Setup/Settings** — A special menu (usually accessed by pressing a key like F2, Delete, or Esc at startup) where you can change hardware settings, like boot order or system clock.
- **Non-Volatile Storage** — BIOS is stored on a special chip (often a ROM or flash memory chip) that retains its data even when the computer is off, unlike RAM.
- **BIOS vs UEFI** — UEFI is the modern replacement for traditional BIOS, offering more features and faster boot times (covered in more detail separately).
