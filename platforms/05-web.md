- [Frontend Mentor](https://www.frontendmentor.io/) — real designs to build against, with a community review.
- [DevChallenges](https://devchallenges.io/) — full-stack briefs, from a landing page to an app.
- [roadmap.sh Projects](https://roadmap.sh/projects) — project ideas graded by level, for every stack.
- [Full Stack Open](https://fullstackopen.com/) — University of Helsinki's free React and Node course.
- [CodePen](https://codepen.io/) — front-end sketchpad; also the best place to read other people's CSS.
- [StackBlitz](https://stackblitz.com/) — full Node projects in the browser, instantly.
- [Replit](https://replit.com/) — collaborative online IDE across many languages.
- [JSFiddle](https://jsfiddle.net/) — quick HTML, CSS and JavaScript scratchpad.
