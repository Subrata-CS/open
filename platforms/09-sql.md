- [SQLBolt](https://sqlbolt.com/) — interactive lessons that take about two hours end to end.
- [SQLZoo](https://sqlzoo.net/) — exercises against real datasets, increasing in difficulty.
- [Mode SQL Tutorial](https://mode.com/sql-tutorial/) — the clearest explanation of window functions anywhere.
- [HackerRank SQL](https://www.hackerrank.com/domains/sql) — graded problems, easy to hard.
- [LeetCode Database](https://leetcode.com/problemset/database/) — SQL questions asked in real interviews.
