---
title: Beginner and fundamentals
about: Start here if you are learning to program at all, not just a new language.
order: 1
---

- [freeCodeCamp](https://www.freecodecamp.org/) — a full curriculum with certificates, entirely free, no upsell.
- [CS50](https://cs50.harvard.edu/) — Harvard's introduction. Still the best first course in computer science.
- [The Odin Project](https://www.theodinproject.com/) — project-driven web development, open source and thorough.
- [MDN Web Docs](https://developer.mozilla.org/) — the reference for HTML, CSS and JavaScript. Trust it over blog posts.
- [Exercism](https://exercism.org/) — small exercises in 70 languages, with human mentors if you want them.
- [W3Schools](https://www.w3schools.com/) — quick syntax lookups when you just need the shape of something.
- [Codecademy](https://www.codecademy.com/) — guided interactive lessons; the basics are free.
- [SoloLearn](https://www.sololearn.com/) — bite-sized lessons that work well on a phone.
