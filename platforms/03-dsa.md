- [LeetCode](https://leetcode.com/) — the interview standard. Work by pattern, not by number.
- [NeetCode](https://neetcode.io/) — the same problems, ordered so each one teaches the next.
- [CSES Problem Set](https://cses.fi/problemset/) — 300 problems that cover the whole classical syllabus.
- [InterviewBit](https://www.interviewbit.com/) — a guided path with mock interviews.
- [AlgoExpert](https://www.algoexpert.io/) — curated set with video explanations. Paid.
- [GeeksforGeeks](https://www.geeksforgeeks.org/) — the article behind almost every algorithm you will search for.
