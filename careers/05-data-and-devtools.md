- [Snowflake](https://careers.snowflake.com/) — cloud data warehouse; storage and query engine internals.
- [Databricks](https://www.databricks.com/company/careers) — Spark, Delta Lake and the lakehouse; heavy distributed systems.
- [MongoDB](https://www.mongodb.com/careers) — document database, Atlas cloud and storage engine work.
- [Redis](https://redis.io/careers/) — the in-memory data store nearly every backend touches.
- [Elastic](https://www.elastic.co/careers) — Elasticsearch and observability; distributed and remote-first.
- [Confluent](https://careers.confluent.io/) — Kafka and event streaming, from the people who wrote it.
- [Cloudera](https://www.cloudera.com/about/careers.html) — the Hadoop-era data platform, now hybrid cloud.
- [Datadog](https://careers.datadoghq.com/) — monitoring and observability; enormous ingest pipelines.
- [Docker](https://www.docker.com/career-openings/) — containers and Docker Desktop; small team, wide reach.
- [HashiCorp](https://www.hashicorp.com/en/careers) — Terraform, Vault and Consul; infrastructure as code.
- [GitHub](https://github.careers/) — where the code lives; Actions, Copilot and remote-first culture.
- [GitLab](https://about.gitlab.com/jobs/) — all-remote since day one, with a public company handbook.
- [Teradata](https://careers.teradata.com/) — large-scale analytics warehousing for banks and telecoms.
- [Palantir](https://www.palantir.com/careers/) — Foundry and Gotham; forward-deployed engineering roles.
- [Figma](https://www.figma.com/careers/) — browser-based design; WebAssembly, rendering and CRDTs.
