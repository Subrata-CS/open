- [Nand2Tetris](https://www.nand2tetris.org/) — build a computer from logic gates up to an operating system.
- [Write a C Compiler](https://norasandler.com/2017/11/29/Write-a-Compiler.html) — a compiler in small, testable stages.
- [Build Your Own Text Editor](https://viewsourcecode.org/snaptoken/kilo/) — kilo, in about a thousand lines of C.
- [Crafting Interpreters](https://craftinginterpreters.com/) — two complete language implementations, free to read online.
- [Operating Systems: From 0 to 1](https://github.com/tuhdo/os01) — write a bootloader and a small kernel from scratch.
- [CodeCrafters](https://app.codecrafters.io/catalog) — rebuild Redis, Docker, git or a HTTP server, with tests.
